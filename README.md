## Controls
These controls are also listed ingame on the bottom right.<br>
w/space - fly<br>
a/d - move<br>
s - fast fall<br>
a/d [double tap] or rmb - dash<br>
lmb - attack<br>
mouse - aim ranged attack<br>
+/- - zoom in/out

## How to play
You're not meant to finish this game on the first attempt.<br>
Learn from each death against him.

## Tips
- Dashing grants I-Frames for a few frames.
- Fast fall helps a lot with dodging attacks.
- For homing missiles, circle around them to dodge them easily.
